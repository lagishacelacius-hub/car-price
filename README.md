# 🚗 Smart Car Price Advisor

## Overview

Smart Car Price Advisor is a Machine Learning web application developed using Python and Streamlit. It predicts the estimated market price of a used car based on its specifications and provides intelligent buying and selling recommendations.

## Features

- Predicts car prices using Machine Learning
- Dynamic Brand → Model selection
- Buy/Sell mode
- Car Health Score
- Deal Evaluation
- Market Price Range
- AI Recommendations
- Interactive Streamlit interface

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- Joblib

## Dataset

The model was trained on a dataset containing 2,500 car records with features such as:

- Brand
- Model
- Year
- Engine Size
- Fuel Type
- Transmission
- Mileage
- Condition

## Machine Learning Algorithm

Random Forest Regression
